使用C语言实现线性代数常见运算，包括行列式、解线性方程组、计算矩阵乘法等。


各个文件对应的功能与原理：

#1、det.c
    利用加减消元以及行列式的展开，递归求解行列式的值。

    例如：
        det([1,2,3],[2,3,4],[3,4,5])
                ||
               \||/
                \/
          det([1,2,3],[0,-1,-2],[0,-2,-4])
                ||
               \||/
                \/
         1*det([-1,-2],[-2,-4])

#2、detplus.c
    与det.c相同的原理，将操作对象转为有理数，利用有理数计算函数代替常规的+-*/

#3、EquationRoot.c
    利用行列式来求解线性方程组的根，仅能求解唯一解情况。
    A=(a_1,a_2,......,a_n) 其中a_i(1<=i<=n)是n维列向量
    b=(b_1,b_2,......,b_n)^T 为n维列向量
    x=(x_1,x_2,......,x_n)^T 为n维列向量

                  Ax=b
                   ||
                  \||/
                   \/
    x_i=det(a_1,...,a_{i-1},b,a_{i+1},...,a_n)/det(A)

#4、MatrixMultiply.c
    计算矩阵乘法（分数矩阵），支持多个矩阵连续相乘。

#5、LA.c
    线性代数相关操作的集合，实现行列式计算、矩阵乘法、乘幂、转置、求逆、加减等操作。
    同时，相较于MatrixMultiply.c，该程序优化了输入。在输入有理数时，程序会自动识别输入形式（整数or分数），并转化为标准形式（对分数约分，统一正负号位置，0的分母归1化）。同时，若出现两个矩阵名称相同的情况，用户可以自行选择处理方式（覆盖or重命名）。
    该程序使用链表来存当前的矩阵，每个节点的数据域保留矩阵信息（行数、列数、数据等），指针域保留下一个节点的地址。添加矩阵、删除矩阵则是在链表上添加、删除节点。
